# jav-data-v1.0

Windows portable release; application version 1.0.0.

- DMM and MGS authentication, product URL search, queued scraping and cover downloads.
- Original Japanese metadata and automatic Emby NFO files; covers use distribution-id-fanart filenames.
- White and red native UI, Table/Cover views, sorting, exact tag filters and numbered pagination.
- Multiple named libraries with import, refresh and removal controls.
- Movie navigation and a fitted cover viewer.
- Cover-download list IDs restart at 1 after the list is cleared; permanent media links remain intact.

Download jav-data-v1.0-windows-x64.zip, extract the entire folder and run jav-data.exe. Python, Qt and the browser runtime are included. Requires Windows 10/11 x64 and a Japan IP connection that covers the app and downloads. Complete age confirmation and any required login in Website Authentication. A DMM account is needed for products requiring sign-in.

The clean ZIP contains no personal database, cookies, account session, downloaded media or history. First launch creates an empty database and browser profile. Consult README.md for searching, scraping, storage and safe updates. The source snapshot and bundled README match this release.
